# 🚀 JGNEXT Escola de Idiomas

> Sistema de gestão completo para rede de escolas de idiomas com múltiplas unidades, cobrindo matrículas, turmas, presença, avaliações, financeiro e portais de aluno e professor. Centraliza a operação acadêmica e financeira com painéis gerenciais para o dono e coordenação.

## 🛠️ Como Executar Localmente

```bash
# 1. Instalar dependências
npm install

# 2. Configurar variáveis de ambiente
cp .env.example .env # se aplicável

# 3. Iniciar servidor de desenvolvimento
npm run dev
```
